# Photos Directory (โฟลเดอร์สำหรับใส่รูปภาพผลงาน)

โฟลเดอร์นี้ใช้สำหรับจัดเก็บไฟล์ภาพผลงานที่จะนำมาแสดงบนหน้าเว็บแบบ Pure Picture-Based

### คำแนะนำในการเตรียมรูปภาพ:
1. **การตั้งชื่อไฟล์:** แนะนำให้ตั้งชื่อเป็น `01.jpg`, `02.jpg`, `03.jpg`, ... หรือตามที่กำหนดไว้ใน `src/config/gallery.ts`
2. **ขนาดและความละเอียดภาพที่แนะนำ:**
   - ความกว้าง (Width): 2400px – 3200px (คมชัดระดับ Retina display แต่ไม่หนักเกินไป)
   - สกุลไฟล์: `.jpg`, `.jpeg`, หรือ `.webp`
   - แนะนำการบีบอัดคุณภาพประมาณ 82%–88% sRGB
3. **การอัปเดตข้อมูลสเปกกล้อง:**
   - เมื่อเพิ่มหรือเปลี่ยนรูป ให้เข้าไปอัปเดต metadata (กล้อง, เลนส์, ค่ารูรับแสง, ความเร็วชัตเตอร์, ISO, พิกัด) ได้ที่ `src/config/gallery.ts`
